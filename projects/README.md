# Projects

One folder per method. Each student is assigned exactly one.

| Folder | Method | Project-specific focus |
|--------|--------|------------------------|
| [`01_decision_trees`](01_decision_trees/) | Decision Trees / Random Forests | depth; relate to random forest |
| [`02_svm`](02_svm/) | Support Vector Machines | Class weights; relate to logistic regression |
| [`03_adaboost`](03_adaboost/) | AdaBoost | Weak-learner count/complexity; relate to Decision Trees |
| [`04_gradient_boosting`](04_gradient_boosting/) | Gradient Boosting | Learning rate × estimators × overfitting; vs AdaBoost |
| [`05_mlp`](05_mlp/) | Multilayer Perceptron | Depth, width, activations; relate to logistic regression |
| [`06_gaussian_processes`](06_gaussian_processes/) | Gaussian Processes | Kernels, hyperparameters, uncertainty; relate to SVM |



### The key objectives:
- [ ] Develop the skills to understand a concept beyond a simple analogy.
- [ ] Turn the theoretical knowledge of lectures into working knowledge.
- [ ] Develop skills to use AI tools such as ChatGPT, Claude, etc. to understand a complex topic.
- [ ] Gaining experience in dealing with real-world problems and its challenges.



#### Note
* You are allowed (and encouraged) to use AI. But, putting anything into this project (as well as into your final presentation) is treated as your knowledge. Please make sure you uphold the academic integirty standards. When in doubt, please ask!

* Do not treat this project similar to the mini-projects. Here, the instructions are very brief and each student may face a unique set of challenges. It is important that you continuously disucss your progress and challenges with the instructor.

* You are asked to learn about a topic that is not covered in lectures. This is by design. The knowledge you gained in this course is the tool you need to complete this project.

### What to Prepare
* Create your own project (by copying/forking this project) and push it to your own (publicly accessible) repository.
* Continiously commit/push to your repository with informative messages.
* Prepare your final presentation (slides).


### Milestones
* Meet with me as many times as you need to make sure that you are on track. This can be done in person or remotely.
* 11/16: 50%-progress presentation (give a 10-min talk with slides)
* 12/14: Final presentation (replacing the final exam)


### Rubric
* Theoretical understanding (40%)
* Flare forecasting using the assigned model and thorough analysis of the findings (30%)
* Investigations for connecting the theory to practice (20%)
* Quality of presentation + quality of code (10%)
* Continuous push/commit with meaningful messages.


### Red flag
* A mismatch between what is delivered and the student's understanding (results in the grade F, potentially with an academic dishonesty report.)
