# Project 04 — Gradient Boosting

Your task is to understand the inner-working of **gradient boosting**. Then, use gradient boosting to predict solar flares. The challenges in the applied portion of the project should guide you to expand on the theoretical portion of the project.

## Resources (scikit-learn)

**Call the model**

- [`GradientBoostingClassifier`](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.GradientBoostingClassifier.html) — `sklearn.ensemble`
- [`HistGradientBoostingClassifier`](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html) — faster histogram-based variant

**Learn from the docs**

- [Gradient Tree Boosting user guide](https://scikit-learn.org/stable/modules/ensemble.html#gradient-boosting)
