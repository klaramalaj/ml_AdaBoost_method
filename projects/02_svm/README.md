# Project 02 — Support Vector Machines (SVM)

Your task is to understand the inner-working of **support vector machines**. Then, use an SVM to predict solar flares. The challenges in the applied portion of the project should guide you to expand on the theoretical portion of the project.

## Resources (scikit-learn)

**Call the model**

- [`SVC`](https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVC.html) — `sklearn.svm`
- [`LinearSVC`](https://scikit-learn.org/stable/modules/generated/sklearn.svm.LinearSVC.html) — optional linear variant
